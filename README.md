# TunePeg: The Robot Guitar Tuner

## Project Summary

TunePeg was the world's first fully autonomous guitar tuning machine, embedded inside the headstock of the Gibson Robot Guitar. It uses neural networks, advances non-deterministic audio analysis, and precision micro-gear engineering to tune each string automatically.

## Achievements

- CES 'Best of Show' Award
- Commercial success with Gibson
- Sub-degree rotation accuracy with <30g device
- Developed new MIM-based micro gear manufacturing
- Pioneered early use of neural nets for real-time acoustics

## Technical Highlights

- Custom AI frequency detection
- Metal Injection Molding (MIM) micro-gear production
- Autonomous motor control under acoustic feedback
